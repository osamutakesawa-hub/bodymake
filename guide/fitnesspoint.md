# FitnessPoint のトレーニングログ連携

ヘルスケア経由だと「筋トレをした」ことしか分かりません。FitnessPoint の記録（種目・重量・回数）を取り込むと、次のことができるようになります。

- **今日のメニューに目標重量が出る**：前回の同じメニューの記録から「前回 60kg × 10・9・8 → 今日の目標 60kg × 10・10・9」を自動で出します。全セットが上限回数に届いたら「62.5kg に挑戦」と表示します
- **筋力の推移**：種目ごとの推定1RM（1回挙げられる最大重量の推定）と、4週間での伸び
- **部位別の週セット数**：背中・肩・脚・胸・腕が、それぞれ週10〜20セット（筋肥大の目安）に入っているか
- **提案**：自己ベスト更新・停滞している種目・主要種目の筋力低下（＝筋肉が落ち始めたサイン）を検知

取り込み方は2通りです。

| 方法 | 用途 | 必要なもの |
|---|---|---|
| **CSV** | 過去ログの一括インポート | なし |
| **スクリーンショット** | 毎日の記録 | `ANTHROPIC_API_KEY`（Claude が画像から重量・回数を読み取ります） |

どちらも、ファイルを GitHub の `data/inbox/` フォルダに置くと自動で取り込まれます（数十秒〜1分）。
取り込みに失敗したファイルは `data/inbox/failed/` に移動し、理由が `〜.error.txt` に書かれます。

## 準備：送信用ショートカット「BodyMake トレ記録」を作る（1回だけ）

CSV とスクリーンショットのどちらも、このショートカット1つで送れます。
GitHub のトークンは、ヘルスケア同期で作ったもの（Contents: Read and write）をそのまま使います。

ショートカットアプリ → ＋ → 右上の ⓘ（詳細）で **「共有シートに表示」をオン**、受け付ける入力を **「画像」と「ファイル」** にします。

1. **もし**「ショートカットの入力」が **値がない** 場合
   - **最新のスクリーンショットを取得**（件数：1）
   - そうでなければ：（何もしない）
   - 終了 → このブロックの結果を変数 `送るもの` にする
   > 共有シートから使えばそのファイルを、ホーム画面から使えば直前のスクショを送ります
2. **繰り返す（各項目）**：`送るもの`
   1. **日付** → **日付をフォーマット**（カスタム `yyyy-MM-dd-HHmmss`）→ 変数 `時刻`
   2. **ファイルの詳細を取得** → **ファイル拡張子**（対象：繰り返し項目）
   3. **もし** ファイル拡張子 が `csv` である
      - **テキスト**：`時刻`-`繰り返しインデックス`.csv → 変数 `ファイル名`
      - **Base64エンコード**（繰り返し項目、改行：**なし**）→ 変数 `中身`
   4. そうでなければ（画像）
      - **画像を変換**：JPEG・品質 0.8（繰り返し項目）
      - **テキスト**：`時刻`-`繰り返しインデックス`.jpg → 変数 `ファイル名`
      - **Base64エンコード**（変換した画像、改行：**なし**）→ 変数 `中身`
   5. **URLの内容を取得**
      - URL：`https://api.github.com/repos/osamutakesawa-hub/bodymake/contents/data/inbox/` の後ろに変数 `ファイル名`
      - 方法：**PUT**
      - ヘッダ：`Authorization` = `Bearer github_pat_xxxx`、`Accept` = `application/vnd.github+json`
      - 本文を要求（JSON）：`message`（テキスト）= `FitnessPoint 記録`、`content`（テキスト）= 変数 `中身`
3. **通知を表示**：`FitnessPoint の記録を送りました`

ホーム画面に追加しておくと、ワンタップで直前のスクショを送れます。

## 1. 過去ログを CSV でインポート

1. FitnessPoint の **書き出し（エクスポート）** 機能で CSV を作り、「ファイル」に保存します（PRO 版の機能の場合があります）
2. 「ファイル」アプリで CSV を長押し → **共有** → **BodyMake トレ記録**
3. 1分ほどでダッシュボードの「筋力の推移」に過去分が表示されます

- CSV に入っている日の記録は、その内容で **置き換え** ます。何度インポートしても重複しません
- 列名は自動判定します（`Date / Exercise / Weight / Reps`、`日付 / 種目 / 重量 / 回数` など。lbs は kg に換算）
- 列を判定できなかった場合は `data/inbox/failed/〜.error.txt` にヘッダの内容が残ります。その内容を教えてもらえれば対応します

> パソコンからでも：GitHub のリポジトリ → `data/inbox` フォルダ → **Add file → Upload files** で CSV を置いても取り込まれます。

## 2. 毎日の記録をスクリーンショットで送る

1. トレーニングが終わったら、FitnessPoint の **その日のワークアウト詳細画面**（種目と各セットの重量・回数が並んでいる画面）を表示します
2. スクリーンショットを撮ります。1画面に収まらない場合は、スクロールして複数枚撮ります
3. 次のどちらかで送ります
   - **写真アプリ** でスクショを選択（複数可）→ 共有 → **BodyMake トレ記録**
   - ホーム画面の **BodyMake トレ記録** をタップ（直前のスクショ1枚を送信）

- 同じ日に何枚送ってもOKです。同じ種目は新しい内容で置き換え、新しい種目は追加します
- 日付は画面に表示された日付を使います。読み取れない場合は送った日になります
- 前日のトレーニングを翌日に送るときは、日付が写るように撮ってください
- 読み取りには Claude を使います。1枚あたり数円程度の API 料金がかかります

### うまく読み取れないとき
- ワークアウトの **一覧画面ではなく詳細画面** を撮る
- 文字が小さすぎる場合は、拡大表示にして撮る
- 失敗したファイルは `data/inbox/failed/` に残ります。理由は同じ名前の `.error.txt` で確認できます

## 自動でつながるしくみ

```
FitnessPoint ─CSV/スクショ→ ショートカット ─PUT→ GitHub data/inbox/
   → GitHub Actions（import-training.mjs）
       CSV  → 列を自動判定して日別ログに変換
       画像 → Claude が種目・重量・回数を読み取り
   → data/training/YYYY-MM-DD.json → 分析 → ダッシュボード
```

- 筋トレログがある日は、ヘルスケアにワークアウトがなくても「筋トレ1回」と数えます
- 筋力の推移（推定1RM）は **重い日の記録だけ** で判定します。軽い日は重量を落としているためです
- 今日の目標は、**同じ部位の前回の記録** から出します。曜日をずらしてトレーニングしても、種目の部位で照合します
  - 軽い日は前回の軽い日の記録から、重い日は前回の重い日の記録から出します
