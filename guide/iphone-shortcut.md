# iPhone 連携ガイド（ショートカットで自動送信）

睡眠・食事・トレーニング・体重のアプリはそれぞれ別ですが、どれも **Apple ヘルスケア** にデータを書き込めます。
ヘルスケアを「集約ハブ」にして、iOS 標準の **ショートカット** アプリで1日数回、自動で GitHub に送ります。

```
睡眠アプリ ─┐
食事アプリ ─┼─▶ ヘルスケア ─▶ ショートカット（自動実行）─▶ GitHub Actions ─▶ 分析 ─▶ ダッシュボード
筋トレアプリ ┤                                   (repository_dispatch)
体重計アプリ ┘
```

---

## ステップ1：各アプリ → ヘルスケアの連携をオンにする

各アプリの設定にある「ヘルスケア連携」「Apple Health」をオンにし、**書き込み（データの送信）** を許可します。

| 種類 | ヘルスケアの項目 | 確認する場所（ヘルスケア → ブラウズ） |
|---|---|---|
| 体重 | 体重・体脂肪率（・除脂肪体重） | 身体測定値 |
| 睡眠 | 睡眠 | 睡眠 |
| 食事 | 摂取エネルギー・タンパク質・脂質・炭水化物 | 栄養 |
| トレーニング | ワークアウト | アクティビティ → ワークアウト |
| 歩数 | 歩数（iPhone / Apple Watch が自動記録） | アクティビティ |

> 確認方法：ヘルスケアアプリで各項目を開き、「データソースとアクセス」に該当アプリが表示され、今日の値が入っていればOKです。

---

## ステップ2：GitHub のトークンを作る（1回だけ）

1. GitHub → 右上アイコン → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. 設定
   - Token name: `bodymake-iphone`
   - Expiration: 最長（1年）
   - Repository access: **Only select repositories → `bodymake`**
   - Permissions → Repository permissions → **Contents: Read and write**（他は不要）
3. 生成された `github_pat_...` をコピー（この画面でしか表示されません）

> トークンはショートカットの中にだけ保存してください。期限が切れたら同じ手順で再発行し、ショートカットのヘッダーを差し替えます。

---

## ステップ3：ショートカット「BodyMake 同期」を作る

ショートカットアプリ → 右上「＋」→ 以下のアクションを上から順に追加します。
（「アクションを検索」に **太字の名前** を入力すると見つかります）

### 3-1. 日付

1. **日付** →「現在の日付」
2. **日付をフォーマット** → 形式「カスタム」、書式 `yyyy-MM-dd` → 名前を `日付` に変更（変数を長押し →「名前を変更」）

### 3-2. 体重・体脂肪率（最新1件）

3. **ヘルスケアサンプルを検索**
   - 種類: **体重**
   - フィルタ: 開始日 が **今日** である
   - 並べ替え: 開始日、**新しい順** / 制限: **1件**（重要：2件以上だと合計されてしまいます）
4. 変数名を `体重` に
5. 同様に **体脂肪率**（制限1件）→ 変数名 `体脂肪`

### 3-3. 睡眠（昨夜）

6. **ヘルスケアサンプルを検索**
   - 種類: **睡眠分析**
   - フィルタ: 開始日 が **過去1日** の範囲 / 値 が **就寝中ではない** / 値 が **覚醒ではない**
     （使っている睡眠アプリが「就寝中」しか記録しない場合は、値のフィルタを外してください）
7. **ヘルスケアサンプルの詳細を取得** → **継続時間**
8. **統計を計算** → **合計** → 変数名 `睡眠`

### 3-4. 食事（今日の合計）

9. **ヘルスケアサンプルを検索** → 種類 **摂取エネルギー**、開始日が **今日** → 変数名 `カロリー`
10. 同様に **タンパク質** / **脂質** / **炭水化物** → 変数名 `P` / `F` / `C`

> 複数件のサンプル（朝・昼・夜…）は、受け取った側で自動的に合計します。

### 3-5. 歩数・ワークアウト

11. **ヘルスケアサンプルを検索** → 種類 **歩数**、開始日が **今日** → 変数名 `歩数`
12. **ヘルスケアサンプルを検索** → 種類 **ワークアウト**、開始日が **今日** → 変数名 `ワークアウト`
    （種類名「筋力トレーニング」「ランニング」など から筋トレ／有酸素を自動判定します）

### 3-6. GitHub に送信

13. **URLの内容を取得**
    - URL: `https://api.github.com/repos/osamutakesawa-hub/bodymake/dispatches`
    - 方法: **POST**
    - ヘッダ:
      | キー | 値 |
      |---|---|
      | `Authorization` | `Bearer github_pat_xxxxxxxx`（ステップ2のトークン） |
      | `Accept` | `application/vnd.github+json` |
    - 本文を要求: **JSON**
      | キー | 型 | 値 |
      |---|---|---|
      | `event_type` | テキスト | `health-sync` |
      | `client_payload` | 辞書 | ↓ |

    `client_payload`（辞書）の中身：

    | キー | 型 | 値 |
    |---|---|---|
    | `date` | テキスト | 変数 `日付` |
    | `weight` | 辞書 | `kg`: `体重` / `bodyFatPct`: `体脂肪` |
    | `sleep` | 辞書 | `minutes`: `睡眠` |
    | `nutrition` | 辞書 | `kcal`: `カロリー` / `proteinG`: `P` / `fatG`: `F` / `carbsG`: `C` |
    | `activity` | 辞書 | `steps`: `歩数` |
    | `workouts` | テキスト | `ワークアウト` |

14. ショートカット名を **BodyMake 同期** にして保存。▶︎ で一度実行し、ヘルスケアへのアクセスを「許可」します。

成功すると何も表示されません（GitHub は空のレスポンスを返します）。
GitHub のリポジトリ → **Actions → Sync health data** に実行が出ていれば成功です。ログの `Ingest` ステップに保存された項目が表示されます。

### 値の単位について

ショートカットが返す値の形式はiOSのバージョンで多少異なりますが、受け取る側で吸収します。

- `72.4 kg` / `72.4` / `2,100 kcal` → 数値部分を使用
- 睡眠：`7:12`、`7時間12分`、`7.2`（時間）、`432`（分）、`25920`（秒）のどれでもOK
- 体脂肪率：`18` でも `0.18` でもOK
- 空の項目は無視（その日の既存データは消えません）

## ステップ4：自動実行（オートメーション）を設定

ショートカットアプリ → 下の **オートメーション** → ＋ → **個人用オートメーション**

| トリガー | 目的 | 設定 |
|---|---|---|
| **時刻** 毎日 7:30 | 朝の体重・睡眠を送る | 「すぐに実行」 |
| **時刻** 毎日 22:30 | 今日の食事・トレーニングを確定 | 「すぐに実行」 |
| **App** → 食事アプリを「閉じたとき」 | 記録した直後に反映 | 「すぐに実行」 |
| **App** → 筋トレアプリを「閉じたとき」 | トレ直後に反映 | 「すぐに実行」 |

それぞれ、実行するアクションに **ショートカットを実行 → BodyMake 同期** を指定します。
同じ日に何回送っても、届いた項目だけ上書きマージされるので問題ありません。

> **注意**：iPhone がロック中だとヘルスケアのデータを読めず、空のまま送られることがあります（空の項目は無視されるので害はありません）。普段 iPhone を使っている時刻にしてください。

### 夜遅くに食事を記録した場合（任意）

ショートカットを複製して「BodyMake 同期（昨日）」を作り、手順1の後に **日付を調整 → 1日を減算** を入れ、
検索条件の「今日」を「昨日」に変えます。朝7:30のオートメーションで両方を実行すると、前日分も確定します。

## 手動で送る・まとめて過去分を送る

Actions → **Sync health data** → **Run workflow** の `payload` 欄に JSON を貼ると手動で投入できます。

```json
{"days":[
  {"date":"2026-11-01","weight":{"kg":74.8,"bodyFatPct":19.8},"sleep":{"minutes":410},"nutrition":{"kcal":2200,"proteinG":140}},
  {"date":"2026-11-02","weight":{"kg":74.6},"workouts":"筋力トレーニング,60,320"}
]}
```

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| Actions に実行が出ない | URL のリポジトリ名、`Authorization: Bearer ` の後のトークン、トークンの権限（Contents: Read and write）と期限 |
| 401 / 404 が返る | トークンの対象リポジトリに `bodymake` が含まれているか |
| 体重が2倍になる | 体重の検索で「制限：1件」になっているか |
| 睡眠が極端に長い | 「就寝中」「覚醒」を除外するフィルタ |
| ダッシュボードが更新されない | ワークフローが **デフォルトブランチ（main）** にあるか（repository_dispatch はデフォルトブランチでのみ動きます） |
